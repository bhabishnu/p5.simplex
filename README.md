# p5.simplex

This is an in-progress Simplex noise addon for p5.js, developed in connection
with [processing/p5.js issue #6152](https://github.com/processing/p5.js/issues/6152).

The addon is intended to support p5.js 1.x and 2.x. The current registration
scaffold is tested against p5.js 1.11.13 and 2.3.0. The repository currently
contains only a compatibility and addon-registration scaffold. Simplex noise
behavior has not been implemented yet.
